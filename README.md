# zero-to-idea
zero to idea is a start-up idea generator built with HTML , CSS and Javascript.
## Features

- Random startup idea generation
- Idea descriptions and problems
- Categories
- Source and date information
- Links to original sources
- Responsive layout

## Built With

- HTML
- CSS
- JavaScript

This was my first project within one month of starting to learn programming:
- JavaScript arrays and objects
- DOM manipulation
- Math.random()
- Flexbox
- CSS transitions
- Responsive layouts
- Gradients and pseudo-elements
